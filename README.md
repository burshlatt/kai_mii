# Домашние задания

Один учебный продукт «Дедлайн» проходит через все задания. Репозитории можно разрезать по папкам.

| Папка | Задание | Что сдавать |
| --- | --- | --- |
| `dz1/` | Сравнение Cloud- и IDE-агентов | `report.md`, скриншоты |
| `dz2/` | Правила и промпт-шаблоны | `hw_ai_rules.md`, `rules.md`, `prompt_templates.md`, `prompt_methodology.md`, `testing.md` |
| `dz3/` | Идея, UI, истории, ТЗ | `project_description.md`, `ui_concepts/`, `user_stories.md`, `technical_specification.md` |
| `deadline/` | Фронтенд, бэкенд, CI и интеграции | код, `README.md`, отчёты `development_report.md`, `backend_documentation.md`, `integration_documentation.md`, `security_audit.md` |

Папки `dz4` отдельно нет: задания 4, 5 и 6 — это последовательная доработка одного репозитория `deadline/`.

Сырые ответы субагентов, на которых собраны отчёты по правилам и цепочке промптов, лежат в `dz2/agent_outputs/`.
