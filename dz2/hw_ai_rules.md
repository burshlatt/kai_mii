# Проект и стек

## Задача

«Дедлайн» — веб-приложение, в котором студент видит свои учебные задания, дедлайны и просрочку. Чужие списки недоступны. Это не общий планировщик команды и не мессенджер.

Проблема: задания живут в чатах, почте и голове. Дата сдачи всплывает вечером накануне.

Пользователь: студент вуза, который ведёт несколько предметов одновременно.

## Стек

- Фронтенд: React 18, TypeScript, Vite, Tailwind CSS, React Router.
- Бэкенд: Node.js, Express, TypeScript, PostgreSQL через `pg`, Zod.
- Сессия: JWT в httpOnly-cookie, отдельная CSRF-cookie.
- Вход: почта и пароль, плюс заготовки OAuth Яндекс ID и Google.
- Инфраструктура: `docker-compose` для PostgreSQL, API и nginx. Локально для проверки использован PostgreSQL 16.
- Тесты: `node:test` на API и Vitest на чистые функции и карточку.

## Требования к коду и архитектуре

- Доменные правила (просрочка, фильтр, сводка, валидация) не смешиваются с SQL и разметкой.
- SQL только параметризованный. Каждое задание читается и меняется с условием `user_id` текущего пользователя.
- Интерфейс на русском, идентификаторы в коде на английском.
- Компонент умеет показать загрузку, ошибку и пустые данные.
- Секреты не попадают в репозиторий и в логи.
- Тип `any`, default-экспорт и inline-стили запрещены. Это зафиксировано в `rules.md` и продублировано в `deadline/.cursorrules`.
